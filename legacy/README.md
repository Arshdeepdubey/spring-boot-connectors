# legacy/

This holds the repository's previous contents, unchanged: a single-module Spring Boot CRUD demo
app (`com.example.gemini`, artifact `gemini-hello`, project name "Posthere") backed by an
in-memory H2 database.

It has nothing to do with the connector platform in the rest of this repository (`common/`,
`rest-to-s3-connector/`, `s3-to-rest-connector/`, `rest-to-db-connector/`) — it is kept here only
for reference/history. See [`posthere-app/README.md`](posthere-app/README.md) for how to run it.
